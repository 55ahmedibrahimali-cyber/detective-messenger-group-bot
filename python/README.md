# 🐍 منظومة أدوات Python لبوت المحقق (Detective Bot)

تم بناء 4 أدوات احترافية متكاملة بلغة Python لتطوير وتشغيل ومراقبة البوت وحمايته من حظر فيسبوك.

---

## 📁 محتويات المجلد:

### 1️⃣ مراقب البوت وتنبيهات تيليجرام (`python/monitor/`)
- **الملف:** `monitor.py`
- **الوظيفة:**
  - فحص حالة البوت على السيرفر كل دقيقة عبر SSH.
  - مراقبة استهلاك الرام (RAM) والمعالج (CPU).
  - إرسال تنبيه فوري ومباشر على حسابك أو مجموعتك في تيليجرام إذا توقف البوت، ورسالة تأكيد عند عودته للعمل.
- **التشغيل:** اضغط دبل كليك على `run_monitor.bat`.

---

### 2️⃣ لوحة تحكم ويب سريعة (`python/dashboard/`)
- **الملف:** `app.py`
- **الوظيفة:**
  - واجهة ويب حديثة (Bootstrap 5 RTL) باللغة العربية.
  - عرض حالة البوت المباشرة (Active / Inactive) واستهلاك الذاكرة.
  - زر بضغطة واحدة لإعادة تشغيل البوت على السيرفر.
  - عرض سجلات (Logs) البوت المباشرة دون الحاجة لفتح SSH يدوياً.
  - إمكانية رفع وتحديث `appstate.json` بضغطة زر وتطبيقه على السيرفر فوراً.
- **التشغيل:** اضغط دبل كليك على `run_dashboard.bat` وسيفتح المتصفح تلقائياً على `http://localhost:5000`.

---

### 3️⃣ مستخرج جلسات فيسبوك الذكي (`python/appstate_extractor/`)
- **الملف:** `extract_appstate.py`
- **الوظيفة:**
  - يفتح متصفح Chromium تلقائياً موجه بالكامل عبر بروكسي السيرفر (`13.48.58.210`).
  - بمجرد تسجيل دخولك لحساب البوت، يكتشف الكوكيز تلقائياً ويسحب الجلسة ويحولها إلى صيغة `appstate.json` المعيارية للبوت ويحفظها في المشروع.
- **التشغيل:** اضغط دبل كليك على `run_extractor.bat`.

---

### 4️⃣ محلل الذكاء الاصطناعي للعبة (`python/ai_analyzer/`)
- **الملف:** `ai_detective.py` و `demo_analysis.py`
- **الوظيفة:**
  - تحليل محادثات اللاعبين في مجموعات الماسنجر والتيليجرام.
  - حساب نسبة الشبهة (Suspicion Score) لكل لاعب من 0 إلى 100%.
  - رصد عبارات التهرب، الدفاع المفرط، ومحاولات تشتيت الانتباه لكشف الجاسوس تلقائياً.
- **التجربة:** اضغط دبل كليك على `run_demo.bat`.

---

## ⚙️ التثبيت على جهازك (Windows):
إذا لم يكن Python مثبتاً على جهازك، يمكنك تثبيته بأحد الطرق الآتية:
1. كتابة الأمر في موجه الأوامر (PowerShell):
   ```powershell
   winget install Python.Python.3.11
   ```
2. أو تحميله مباشرة من الموقع الرسمي: [python.org](https://www.python.org/downloads/) مع التأكد من تفعيل خيار **Add Python to PATH**.
