# من أي فيلم كرتون؟

اكتب `كرتون` في المجموعة، ثم خمّن اسم الفيلم الذي قيلت فيه العبارة. أول إجابة صحيحة تحصل على نقطة. يمكن استخدام `/قواعدكرتون` لعرض التعليمات. الأمران القديمان `جملةكرتون` و`/قواعدجملةكرتون` ما زالا يعملان.

لا تتضمن اللعبة حوارات جاهزة. أضف فقط مقتطفات تملك حق استخدامها أو لديك إذن بنشرها إلى `quotes.json`. يمكن نسخ البنية من `quotes.sample.json`:

| الحقل | الوصف |
| --- | --- |
| `quote` | المقتطف الذي سيظهر للاعبين (280 حرفاً كحد أقصى) |
| `film` | اسم الفيلم والإجابة الأساسية |
| `alt` | عناوين بديلة مقبولة للفيلم (اختياري) |

يمكن تغيير مسار الملف عبر `CARTOON_MOVIE_QUOTES_PATH`. أعد تشغيل البوت بعد تعديل الملف.
