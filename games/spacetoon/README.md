# أكمل الأغنية (نسخة سبيستون)

يظهر البوت سطراً من أغنية، وأول لاعب يرسل السطر التالي بشكل صحيح يفوز بنقطة.

## إضافة الأغاني
أضف الأغاني في `games/spacetoon/songs.json` (انظر `songs.sample.json`). كل عنصر:

| الحقل | الوصف |
| --- | --- |
| `line` | السطر الذي يظهر للاعبين (مطلوب) |
| `answer` | السطر المطلوب إكماله (مطلوب) |
| `alt` | صياغات بديلة مقبولة (اختياري) |
| `show` | اسم المسلسل كتلميح (اختياري) |

ملاحظة: لم يُضَف أي نص من كلمات الأغاني الأصلية في الكود، لأن كلمات أغاني سبيستون محمية بحقوق النشر، فالمحتوى مسؤولية من يضيفه.
يمكن تغيير مسار الملف بالمتغير `SPACETOON_SONGS_PATH`. أعد تشغيل البوت بعد أي تعديل.

## الأوامر
`/أغنية` أو `/سبيستون` لبدء جولة، `/قواعدالأغنية` للشرح.
التصحيح متسامح مع الأخطاء الإملائية الصغيرة ونقص كلمة أو كلمتين كحد أقصى، مع الحفاظ على ترتيب الكلمات ورفض الكلمات الزائدة.
